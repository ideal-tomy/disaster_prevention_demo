## 4. 開設判定のルール

判定は次の4つのみ。色を付けて埋めない。

| 判定 | 意味 | 付ける条件 |
|---|---|---|
| 使える | 指定避難所として開設の記録がそろっている | 消防・発電機・受水槽・外壁・扉の直近記録があり、期限切れと「使えない」相当の指摘がない |
| 条件付きで使える | 開設はできるが、条件か未確認がある | 平常時の記録が1件以上残り、その記録が理由になる |
| 使えない | 開設の記録が「使えない」を示している | 平常時の記録が理由になる。カメラだけでは使えないにしない |
| 確認できていない | 判定しない | 点検記録がない。台帳の収容人数があっても判定に使わない |

市庁舎は指定避難所ではない。判定は「使える」（職員が残る拠点）。避難所の開設数には入れない。

|---|---|---|
| 使える | 13 | 12 |
| 条件付きで使える | 4 | 4 |
| 使えない | 2 | 2 |
| 確認できていない | 3 | 3 |
| 合計 | 22 | 21 |
