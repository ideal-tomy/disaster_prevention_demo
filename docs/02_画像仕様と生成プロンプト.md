# 画像仕様と生成プロンプト｜防災施設コンソール

カット定義の正本。GPT に貼る完成文（再生成セット）は [../防災施設コンソール_画像生成用完成プロンプト一覧.md](../防災施設コンソール_画像生成用完成プロンプト一覧.md)。実ファイルは `disaster_prevention_demo/public/img/` に `a1.jpg` 形式で置く。

固有名詞と時刻は [04_ペルソナと仮ナレッジ.md](04_ペルソナと仮ナレッジ.md) に従う。市名は翠嶺市。施設名の看板、校名の文字、自治体の紋章は写真に焼き込まない。文字が要る名前は UI が重ねる。

写真は4種類。混ぜると、証拠写真が広告になる。

- **A 印象用:** LPの1枚。市営の総合体育館を、静かに大きく見せる
- **B 証拠写真:** インシデントの抽出静止画。固定カメラの画角。少し粗い。枠は焼かない
- **C 設備のディテール:** 画像確認と点検の根拠。人が見る距離。枠は焼かない
- **D オーバーレイ:** 生成しない。実装が画像の上に重ねる

共通で避けること: 実在の自治体名・ロゴ、被災・けが・崩れた建物、笑顔でカメラを見る人物、スタジオの白背景、読み取れるナンバー、顔のクローズアップ、銃器・ミリタリー、防災のヘルメットの集合写真、赤いバナー文字。

---

## 共通

画面での扱い

- 長辺 1600px、JPEG 品質 72 程度。A だけ長辺 2000px まで可
- ファイルが無いときは、同じ比率の無地の面を出す。レイアウトを崩さない
- B は固定カメラの静止画に見えること。タイムスタンプとカメラIDは写真に焼かない。UI が右下に乗せる
- 検出枠、ラベル、十字、HUD、レーダーはプロンプトに入れない。焼いた枠は使わない

共通の否定（英語プロンプトの末尾に付ける）

> no text, no watermark, no logo, no school name, no license plate characters, no readable signs, no bounding boxes, no HUD, no detection overlay, no face close-up, no injuries, no collapsed buildings, no disaster aftermath, no studio backdrop, no weapons

## D：UIが重ねるもの（生成しない）

実装は [03_UIUXデザイン要件.md](03_UIUXデザイン要件.md)。プロンプトに入れない。

| 要素 | 内容 |
|---|---|
| 検出枠 | 角丸の矩形。線は2px。塗りは半透明にしない。被写体の外側 |
| ラベル | `車両 白バン` / `人物 8名` / `備品`。危険、不審、監視、と書かない |
| カメラID | `CAM-総合-E01` など。写真の下のキャプション |
| 時刻 | `14:08` と `44分前`。04 の現在時刻 14:52 から計算 |
| REC 表示 | 小さな点と「抽出」。ライブ放送のREC絵にしない。文言は「抽出静止画」 |

確からしさ 81% は相関パネルに出す。写真の上には出さない。
