## 1. 完了の定義

市版は全庁を**読む**面である。1棟版が無くても自治体提案が終わる。並べたときだけ、体育館で書いた行が市の判定の根拠に見える。

投影で次ができたら完了とする。

1. 市の一覧で翠嶺市総合体育館（F01）を見る
2. 同じ INC / K-G3 / 14:52 のまま体育館版を開く
3. 市の地図と INC 帯で「22施設の読む画面」だと一目で分かる
4. 市の中で、画像確認を押すと書類の確認者が高木として残る（体育館の岡田とは別アプリ）

実行時のアプリ連携はしない。画面に「市へ送る」も「1棟版が下にある」も出さない。口で「全庁で揃うと、計画の改定に再調査がいらない」と言う。計画の名前は出さない。

## 5. 層3　市の中の書く循環

体育館①の型を、**市セッションの中だけ**に入れる。体育館とは同期しない。
